抽中：Yuki、小周、大刘。

候补（有人放弃时按顺序递补，不重抽）：Coco、小红、阿明、Mia、老王。

复算方法：① 种子 = 「种子原像」的 SHA-256（UTF-8）。② 第 c 次取数（c 从 0 起）= SHA-256（种子 + c 的 8 字节大端）的前 8 字节，按大端读成整数 x。要取 0 到 n−1 之间的整数时，x 小于 2^64 − (2^64 mod n) 就取 x 除以 n 的余数，否则 c 加 1 重取。③ 名单按码位排序，i 从 n−1 降到 1，每步取一个 0 到 i 之间的整数 j，交换第 i 位和第 j 位，最后得到的就是完整顺序。整个过程不用 random 模块。

核对：把本次的输入连同卡片上的结果（claimed）交给 python3 scripts/slot_lottery.py --verify，一致就退出 0，不一致退出 1。随机源原文请自己到公布处再抄一遍，用 --source 传给它。

## 本结果不包含

- 随机源是否真的事先约定、事后无法更改、临场无人能预测：脚本核对不了。这三条只要有一条不成立，就有人能影响结果。
- 名单、名额数和规则是否在随机源公布前就已冻结：由群里的记录证明，脚本只按输入计算。
- 有人放弃后按候补顺序递补是群里的约定，不在脚本的保证里。
